# Community Library Management System

A web-based library management system built with React and Vite.

## Features

- Dashboard showing library statistics and book availability.
- Book management: add, update, and delete books.
- Transaction management: borrow and return books.
- User management with role-based access.
- Login system.
- Local Storage for saving application data.
- Backup and restore functionality.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- Browser Local Storage
